Read this before buying

  • One CFD run per rotor speed, so three independent runs. It is enough to check the blade-passage frequency, not to train a classifier.
  • The CFD is laminar, uses 648,014 cells and has no grid-independence study. Treat pressure amplitudes as indicative only.
  • Probes sit in the body frame, so a flying object passing a fixed ground sensor is not reproduced.
  • Machine-learning results come from simulated ROM data only. The single pressure sensor did not beat the 75% baseline; the fused result of 90.6% accuracy needs an added acoustic channel.
  • No field measurements. This is concept-stage research, not a detector.
